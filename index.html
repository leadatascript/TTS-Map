Trip Distribution GUI Help

This interface lets you load zone polygons, filter visible zones with a CSV, create/edit Direction + Gateway groupings, import/export assignments, show zone labels, optionally launch Google Maps directions from selected zones, and run Gateway Testing Mode with weighted trip visualization.

Required files

  • 1. GeoJSON: Upload the zone boundary polygon file. Only .geojson files are accepted. The tool uses the first GeoJSON property value as the zone ID displayed on the map.
  • 2. Filter CSV: Upload the CSV containing zone IDs and, if applicable, existing Direction/Gateway assignments and trip values. Only .csv files are accepted.

Column and row inputs

  • Start Row: The first CSV row containing actual zone records. If row 1 is headers, use 2.
  • Zone Column: The CSV column containing zone IDs. Use Excel-style letters such as A, B, C.
  • Input Column (Direction): The CSV column containing existing Direction values when using Load Assignments.
  • Input Column (Gateway): The CSV column containing existing Gateway values when using Load Assignments. Multiple gateways are allowed in one cell when they are comma-separated.
  • Input Column (Trip): The CSV column containing the trip value used by Gateway Testing Mode to weight centroid-to-gateway lines and gateway totals.
  • Output Column (Direction): The CSV column where Direction should be written during Final Export. In the default export, Gateway is written to the next column. In Trip Distribution by Gateways export mode, one gateway output column is created for every unique gateway beginning in the next column.
  • Output Filename: The name used for the downloaded export CSV.
  • Site Location (Latitude, Longitude): Optional project/site coordinates entered in latitude, longitude format (for example, 43.882840, -79.440280). This is a coordinate-only field; it does not geocode addresses. If provided, it becomes the default routing location in Google Maps URL Integration.

Main toggles

  • OVERWRITE COLUMNS: When checked, Final Export writes back into the same Direction/Gateway columns that were loaded with Load Assignments. This only works after assignments have been loaded from the CSV. This applies to the standard export only.
  • SHOW ZONE LABELS: Shows or hides zone ID labels on the map polygons.
  • SHOW SITE LOCATION: Displays or hides the Site Location marker on the map when valid coordinates are entered.
  • TRIP DISTRIBUTION BY GATEWAYS: Changes Final Export so the output includes one Direction column and one additional output column per unique gateway with decimal shares (for example, 0.5 = 50%). A warning is shown before exporting because this is an analyst-support approximation that should be verified.

Creating new groups

  • Direction: Enter the Direction value for a new group, such as N, S, EB, or WB.
  • Gateway: Enter the Gateway name for a new group. Multiple gateways can be entered in one group by separating them with commas.
  • Apply Selection: After clicking unassigned zones on the map, this creates or updates a Direction + Gateway group.
  • When a group contains multiple gateways, trips are split evenly across those gateways for Gateway Testing Mode visualization and for the optional gateway distribution export.

Buttons

  • Filter Map: Uses the Filter CSV and Zone Column to show only matching zones on the map.
  • Load Assignments: Reads existing Direction/Gateway assignments from the CSV and rebuilds the Applied Selections legend.
  • Apply Selection: Assigns currently selected map zones to the Direction + Gateway entered in the input boxes.
  • Google Maps URL Integration: Opens the Google Maps setup popup. If Site Location coordinates are provided, they are used as the default routing location. After enabled, clicking zones opens Google Maps directions.
  • Gateway Testing Mode: Activates a separate gateway-testing workflow. A small active-mode bar stays on screen, while gateway setup is handled through a popup similar to Google Maps mode.
  • Final Export: Downloads the CSV with Direction and Gateway values written to the selected output columns, or the gateway share export when that toggle is selected.

Applied Selections legend

  • Each group receives a color and appears in the Applied Selections legend.
  • The checkbox beside a legend item selects that group for editing on the map.
  • When a group is active, clicking one of its zones removes the zone from the group.
  • When a group is active, clicking an unassigned zone adds the zone to that group.
  • The red ✖ removes the entire group.
  • Rename lets you edit the group's Direction and Gateway directly in the legend, then save the changes.

Gateway Testing Mode

  • Use the Gateway Testing Mode button to activate the mode. It has its own mode bar and temporarily repurposes map clicks for gateway point definition instead of zone editing.
  • Every unique gateway currently referenced by the groups must be defined with a gateway point before gateway testing is complete.
  • Gateway definitions are created with a single click on the map.
  • Centroid-to-gateway lines connect from each zone centroid directly to the selected gateway point.
  • Centroid-to-gateway lines use the group color and are weighted by trip share using the values from Input Column (Trip).
  • If the same gateway appears in more than one group, gateway trips are aggregated. The gateway point size reflects the combined total.
  • If a Site Location has been defined and SHOW SITE LOCATION is turned on, the visualization also draws lines from each gateway point to the Site Location, weighted by the total trips assigned to that gateway.
  • You can clear an individual gateway definition from the mode bar and redefine it at any time.
  • You may exit Gateway Testing Mode without defining every gateway if you choose, but the mode will continue warning you about any undefined gateways while active.

Google Maps URL Integration

  • Use selected zone as Origin: The zone-side point becomes the Google Maps route origin. The typed location becomes the destination.
  • Use selected zone as Destination: The zone-side point becomes the Google Maps route destination. The typed location becomes the origin.
  • Location input: Enter coordinates in latitude, longitude format. If the Site Location field has been filled in on the main interface, those coordinates will be reused here by default.
  • If you change the routing coordinates in the Google Maps popup away from the defined Site Location, the tool will show a caution that you are overriding the Site Location for that routing action.
  • Avoid tolls / highways / ferries: Adds Google Maps URL avoid options to the route request.
  • Random point: Uses a random point inside the clicked zone polygon.
  • Clicked point: Uses the exact map point you clicked inside the zone.
  • Exit Google Maps Mode: Leaves Google Maps mode and returns map clicks to normal zone selection/editing behavior.
In Google Maps mode and Gateway Testing Mode, map clicks do not assign or edit groups. Exit the active mode to return to normal editing.
If an error message is displayed in the map interface, try opening the tool in a different web browser.
